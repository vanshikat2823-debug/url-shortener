# URL Shortener

A URL Shortener application built using Spring Boot, MySQL, and JavaScript.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript

## Features

- Create short URLs
- Redirect to original URLs
- URL validation
- Exception handling
- Unique short codes

## How to Run

1. Configure MySQL database.
2. Set database environment variables.
3. Run the Spring Boot application.
